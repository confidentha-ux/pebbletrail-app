# PebbleTrail

PebbleTrail is an interactive reflection app for reading the judgment behind a decision. It guides a person through an initial choice, the standard shaping that choice, and a second judgment.

## Current prototype

- Brand introduction and onboarding
- First decision situation: an important request from a friend
- Guided reason selection
- Rejudgment
- First discovery screen
- Responsive desktop and mobile layout

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

Open the local address shown in the terminal.
